# RabbitMQ Designer

Визуальный проектировщик топологии RabbitMQ с live-симуляцией и экспортом — полностью офлайн, открывается одним файлом.

Аналог [tryrabbitmq.com](https://tryrabbitmq.com) + визуальный язык [Kafka-visualization](https://softwaremill.com/kafka-visualisation/).

![RabbitMQ Designer](https://img.shields.io/badge/RabbitMQ-AMQP%200-9-1-ff6600) ![Interface](https://img.shields.io/badge/интерфейс-RU%20%7C%20EN-blue) ![Offline](https://img.shields.io/badge/offline-100%25-green)

## Что умеет

- **Дизайн топологии мышью** — поставщик (producer), экчейндж (exchange: `direct` / `fanout` / `topic` / `headers`), очередь (queue), потребитель (consumer), DLX/DLQ. Связи (bindings) тянутся перетаскиванием от порта или кликом.
- **Live-симуляция** — сообщения летают по топологии, видны маршрутизация, requeue, TTL, dead-letter, потери. Журнал событий с объяснением каждого маршрута.
- **Экспорт** одним кликом:
  - `definitions.json` — импорт в реальный RabbitMQ (`rabbitmqctl define_definitions_file`);
  - Java-каркас под **Spring AMQP** (`RabbitMqConstants.java`, `RabbitConfig.java`, `AppEvent.java`, `EventPublisher.java`);
  - Markdown-документация (RU/EN, 14 разделов) — можно отправить на нормоконтроль.
- **Автосохранение и защита от потери данных** — работа не пропадает при перезагрузке, смене вкладки или краше браузера.
- **Проекты** — именованные схемы в браузере + выгрузка/загрузка файла `.rmq.json`.
- **RU/EN** — переключение языка на лету.
- **0 зависимостей** — работает с `file://`, весь стек (JSZip) подгружается с CDN и деградирует gracefully.

## Как запустить

Просто открыть `index.html` в любом современном браузере. Сервер не нужен.

Или локальным сервером:

```
npx serve .
# или
python -m http.server 8000
```

## Автосохранение и проекты

Для инструмента под нормоконтроль потеря схемы недопустима, поэтому работа сохраняется автоматически.

**Как это работает**

1. **Автосохранение** — после любого изменения топологии (с debounce 600 мс) схема пишется в `localStorage` браузера. Никаких сетевых запросов, ничего не уходит наружу.
2. **Восстановление** — при следующем открытии страницы схема восстанавливается автоматически, вы получаете уведомление «Восстановлена схема от …».
3. **Индикатор в шапке** — показывает состояние: `Сохранено` / `Автосохранено` / `Есть несохранённые изменения`.
4. **Предупреждение при перезагрузке** — если изменения не сохранены как проект, браузер спросит «Уйти со страницы?». Ничего не теряется: автосохранение всё равно восстановит схему, но вы будете знать, что проект ещё не зафиксирован.
5. **Замена схемы** (пресет, импорт `definitions.json`) при несохранённых изменениях спрашивает: `Сохранить проект` / `Не сохранять` / `Отмена`.

**Проекты** (кнопка `Проекты` в шапке или `Ctrl`+`S`)

| Действие | Где хранится |
|---|---|
| `Сохранить` | именованный слот в `localStorage` браузера (до 40 проектов) |
| `Скачать .rmq.json` | файл на диске — формат проекта, пригоден для вложения в тикет/репозиторий |
| `Загрузить .rmq.json` | импорт файла проекта (схема сразу попадает в список проектов) |
| `Открыть` / `Удалить` | управление сохранёнными проектами |

Формат `.rmq.json` — это JSON проекта: `app`, `version`, `name`, `vhost`, `package`, `lang`, `exportIncludeUsers`, `nodes`, `links`. Файл открывается в любом браузере и на другой машине.

Автосохранение можно отключить галочкой в окне проектов. Если браузер запрещает `localStorage` (private mode, жёсткие настройки), приложение продолжает работать и честно предупреждает: остаётся только защита от ухода со страницы.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` + drag | панорама холста |
| `Del` / `Backspace` | удалить выбранный узел |
| `Ctrl` + wheel | зум (или колесо) |
| `Ctrl` + `S` | сохранить проект |
| `Enter` в поле | применить значение |

## Структура

```
index.html        — каркас (единый файл для запуска)
style.css         — тёмная тема
i18n.js           — строки RU + EN
presets.js        — пресеты: myproject, fan-out, blank
core.js           — движок: routing, симуляция, dead-letter, счётчики
exporters.js      — definitions.json / Spring AMQP Java / markdown-документ
help-content.js   — справочник
storage.js        — автосохранение, проекты, защита от потери данных
render.js         — SVG-холст, инспектор, тосты, RAF-цикл
test-logic.js     — тесты логики (node test-logic.js)
test-rk.js        — тесты routing key, unit + e2e (node test-rk.js)
```

## Разработка

Тесты запускаются в Node без установки зависимостей:

```
node test-logic.js
node test-rk.js
```

Правила, инварианты продукта и стиль кода — в [CONTRIBUTING.md](CONTRIBUTING.md).
О найденных уязвимостях сообщайте приватно, через вкладку **Security** — см. [SECURITY.md](SECURITY.md).

## Совместимость экспорта

Сгенерированные Java-файлы соответствуют типовому проекту Spring Boot + Spring AMQP: плоские имена классов (`RabbitMqConstants`, `RabbitConfig`, `AppEvent`, `EventPublisher`), без префиксов — кладите прямо в пакет `com.example.config` / `com.example.events`.
